# Network Traffic Analyzer

A Python-based project designed to analyze network traffic
and help understand network communication.

## About

This project is being developed as a learning project
to explore computer networking and Python programming.

## Technologies

- Python
- Wireshark (planned)

## Current Features

- Basic Python application setup
- Initial project structure

## Planned Features

- Network packet analysis
- TCP and UDP traffic statistics
- IP address analysis
- Traffic visualization
